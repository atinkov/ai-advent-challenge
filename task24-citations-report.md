### Q10. Как в пайплайне дня 19 проверяется, что данные между шагами search_docs → summarize → save_to_file переданы без искажений?

_Ожидание: Шаги передают идентификаторы (result_id → source_id, summary_id), а целостность сверяется по sha256: input_sha256 = text_sha256, save.input_sha256 = summarize.output_sha256, файл = file_sha256._

**Ответ:** Проверка целостности передачи данных между шагами пайплайна дня 19 выполняется двумя механизмами: (1) сверка идентификаторов — result_id из search_docs должен совпадать с source_id в summarize, а summary_id из summarize — с summary_id в save_to_file; (2) сверка SHA-256 хешей — text_sha256 результата поиска должен совпадать с input_sha256 в summarize, output_sha256 summarize — с input_sha256 в save_to_file, а file_sha256 файла на диске — с записанным содержимым.
