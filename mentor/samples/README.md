| Папка | Что внутри |
|---|---|
| `12.1-good/` | все требования выполнены: проверки кода и тела ответа, `exitHereIfFailed()` после логина и счетов, снятие с `status().in(200, 400)` + `checkIf`, три assertions с обоснованием порогов в комментарии |

| Требование | Ошибка |
|---|---|
| R1 | у логина нет проверки, что `accessToken` не пуст, и нет `exitHereIfFailed()` |
| R3 | перевод проверяет только код ответа, без поля тела |
| R4 | снятие сверх баланса (400) проверяется как `status().is(200)` — ожидаемый отказ становится KO |
| R8 | нет `details("Login").failedRequests().count().is(0L)` |
| R9 | пороги assertions не обоснованы комментарием |

`mvn -q compile exec:java -Ptask35 -Dexec.args="check"` проверяет, что наставник зачитывает первое решение и находит все пять ошибок во втором.
