## CONVENTIONS
- Maven build, not Gradle. Java 25 both source and target (Corretto 25 is the default `java`).
- LLM calls go through JDK `java.net.http.HttpClient` — no HTTP client library; Jackson only for JSON.
- LLM config resolution: process env > `.env` file (repo root, gitignored, parsed by `LlmClient` — no extra deps) > built-in defaults. Names: `HINDSIGHT_API_LLM_PROVIDER` (must be `openai`), `HINDSIGHT_API_LLM_BASE_URL` (default `https://gpustack.data.lmru.tech/v1`), `HINDSIGHT_API_LLM_MODEL` (default `qwen3.8-27b` — `qwen3.6-27b` 404s on the server), key `LLM_API_KEY` (user's canonical name — no fallbacks; gpustack server requires auth).
- Embeddings (week5): same endpoint and key as chat by default; override with `EMBEDDING_BASE_URL` / `EMBEDDING_API_KEY` / `EMBEDDING_MODEL` (e.g. Ollama: `EMBEDDING_BASE_URL=http://localhost:11434/v1 EMBEDDING_MODEL=bge-m3`). No embedding model reachable → local lexical fallback with a printed warning. An index remembers its embedder; after switching the embedding model re-run day 21, then day 23 (the similarity threshold is embedder-specific).
- `LLM_TIMEOUT_SECONDS` (env / `.env`, default 120, day 34) — timeout of one chat/embedding POST in `LlmClient`; long tool dialogues of a reasoning model may need more.
- `LlmClient.newHttpClient()` — use this (not `HttpClient.newHttpClient()`) in any new code that needs its own `HttpClient`. Normally identical to the JDK default; if env/`.env` `LLM_INSECURE_TLS` is true/1/on, it disables TLS certificate validation entirely. This exists solely as a one-off workaround for an expired/broken cert on the gpustack gateway (`LLM_INSECURE_TLS=1 mvn -q exec:java -PtaskN`) — never set it in a committed `.env`. Used by Task11–Task15.
- IntelliJ project (`.idea/`); `.mvn/wrapper` referenced in `.gitignore` but no wrapper present. **If AGENTS.md is open in the IDE, its buffer can silently overwrite edits made to the file from outside the IDE** (observed while building days 12-13) — close/reload the tab there after an external agent edits this file, or check `git diff AGENTS.md` if a documented day seems to have reverted.

## ANTI-PATTERNS (THIS PROJECT)
- Do not commit `.idea/` or `.omo/` (IDE/agent state) — `.gitignore` only excludes some `.idea` entries.
- No `mvnw` wrapper: do not assume `./mvnw` works; use `mvn` (verify install).
- Do not hardcode API keys in code or commit them — process env or the gitignored `.env` only.
