> - Для спонсора: контракт на период, получает брендинг + ежемесячный PDF-отчёт (активные ученики, число партий, решённых задач, бот-партии).
> - Платёжных модулей, подписок, premium в системе нет.
> 
> **Требования к интерфейсу**
> - **Тёмная тема** по умолчанию (фон `#121212`). Переключатель на светлую — в профиле.
> - **Строго русский язык**, без английского в UI. Глоссарий закреплён (рейтинг, не Elo; капитуляция, не resign).
> - Ходы — кириллицей (`Ке7`), координаты клеток — `a1–h8`.
> - **Mobile-first**: 50 % трафика с телефона. Breakpoints: < 768 / 768–1024 / > 1024. Доска на телефоне — одна + панель ходов.
> - Тёмная доска с контрастной обводкой, фигуры с тенью/обводкой.
> - Кнопки ≥ 44 px, навигация — нижний таб-бар (моб) / сайдбар (десктоп).
> - Адаптация под возраст: младшая — крупные элементы, минимум текста; старшая — плотнее, с аналитикой.
> 
> **Бот для тренировки (в MVP)**
> - Stockfish.js в Web Worker, 3 уровня сложности, задержка хода 1–3 с.
> - Лимит 3 партии/день. Не нагружает сервер (клиентский).
> - Результат в статистику, на рейтинг не влияет.
> 
> **MVP — что в scope**
> - Регистрация по ссылке от тренера (≤ 10 учеников).
> - Партия в реальном времени (блиц 3+2, быстрые 10+5), матчинг внутри группы.
> - Панель тренера: список 10, старт/стоп партии, назначение задач.
> - Задачи (этюды): тренер загружает, ученик решает, автопроверка.
> - Бот (3 уровня).
> - Push-уведомления.
> - PDF для спонсора (5 показателей).
> - Тёмная тема, русский UI, mobile-first.
> 
> **Что не в MVP**
> - Турнирный движок, дерево вариантов, чат группы, родительский дашборд, PWA, спонсорский кабинет, межгрупповые матчи.
> 
> **Дедлайн**
> - **1 месяц** (4 недели).
> - Критерий приёмки: тренер создаёт группу из 10 → ученики играют с телефона (реально + бот) → задачи решаются → PDF сгенерирован.
